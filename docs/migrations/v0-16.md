---
title: Migrating to 0.16
description: One rename, one deprecation, one wire fix. @effect-uai/core/Inbox becomes @effect-uai/core/Settle, the turn meters move under Metrics.Turn, and realtime transcription moves to OpenAI's GA wire.
---

Nothing here breaks a build except one import path, and one set of names is
deprecated but still works. Realtime speech-to-speech
is new in this release and adds nothing you have to change; see
[Realtime](/realtime/).

**One import path changes.** `@effect-uai/core/Inbox` is now
`@effect-uai/core/Settle`. `drainBurst` keeps its name, its signature and its
behaviour, so the call sites do not move.

```diff
- import { drainBurst } from "@effect-uai/core/Inbox"
+ import { drainBurst } from "@effect-uai/core/Settle"
```

If you use the namespace import, `Inbox.drainBurst` becomes
`Settle.drainBurst`.

## Why

`Inbox` held exactly one function, and the same "wait until arrivals go quiet"
idea had grown three separate implementations: `drainBurst` over a queue, a
copy inside the voice-loop recipe over a stream, and the metronome inside
`Metrics.throughput`. `Settle` is the one home for the idea, so a new operator
lands next to the existing one rather than in whichever module needed it first.

## What is new in the module

`settleBurst(stream, settle, options?)` is `drainBurst` over a stream, emitting
one array per burst. It was recipe-local before. Two behaviours changed when it
moved into core, both of which you get for free:

- A failing source now fails the stream. Previously the producer fiber died and
  the queue was closed, so a failure reached the consumer as a clean end of
  stream.
- The internal buffer is bounded (64 by default, `options.capacity` to change
  it). A slow consumer now suspends the source instead of growing memory
  without limit.

`onQuiet(stream, settle, emit)` passes every element straight through and emits
whatever `emit` yields once nothing has arrived for `settle`, at most once per
quiet period. Use it when output must stay live and you only want a boundary
marker, which is what separates it from `settleBurst`.

## Behaviour change in `drainBurst`

A queue that ends mid-burst now returns the batch in hand rather than failing,
so the last batch before a producer finishes is no longer lost. Interruptions
and real failures still propagate. A long-lived inbox that never ends is
unaffected.

## The turn meters move under `Metrics.Turn`

`@effect-uai/core/Metrics` is now organized by the event stream each meter
reads, because that is what makes a meter specific. The old flat names still
work and are deprecated:

```diff
- LanguageModel.streamTurn(request).pipe(Metrics.allMetrics())
+ LanguageModel.streamTurn(request).pipe(Metrics.Turn.allMetrics())
```

The same applies to `timeToFirstToken`, `throughput`, `tokenTotals` and
`timeToCompletion`, and to their option and event types
(`Metrics.Throughput` becomes `Metrics.Turn.Throughput`). Signatures,
behaviour, event shapes and metric names are all unchanged; only where the
name lives moved. The deprecated aliases go in a later minor.

The shared machinery stays flat and does not move: `MetricEvent`,
`Measurement`, `makeEvent`, `isMetricEvent` and `metricEvents` are what every
meter and the exporter agree on. `Telemetry.record` is untouched.

Five namespaces are new, one per event stream plus the two shared pieces.
`Metrics.Realtime` meters a speech-to-speech session with `timeToFirstAudio`
and `usage`; see [Realtime](/realtime/). `Metrics.Transcript.finalLatency`
measures how long after a speaker stops the committed transcript arrives, and
`Metrics.Speech.timeToFirstByte` how long before a synthesized voice starts.
`Metrics.Meter` is the capability-free plumbing the presets are built from
(`Anchor`, `timeToFirst`, `segmentDuration`, `mark`), which is what to reach
for when writing your own meter rather than copying a built-in.
`Metrics.Usage` is the token accounting the meters share, including
`ReducerUsage`, a `Reducer` for `Usage` if you want to sum spend yourself.

## `TranscriptEvent` is a tagged enum

It is now a `Data.TaggedEnum`, which expands to the same `{ _tag } & Props`
union it already was, so events you build as object literals keep compiling
and the tag strings are unchanged. What is new is `TranscriptEvent.$is`,
`$match` and constructors, and that the existing `isFinal`,
`isUtteranceEnded` and friends now accept `unknown`, so they work from a
stream operator scanning a mixed stream.

## Realtime transcription moved to the GA wire

`OpenAIRealtimeTranscriber` still spoke the beta dialect, which OpenAI shut
down on 2026-05-12. It now speaks GA. No code changes are needed, but two
things are worth knowing:

- `vadEvents` stays on unless you pass `false`. Server VAD is what commits a
  turn, and only a committed turn yields a `final`, so a session without it
  emits partials forever. Models that transcribe continuously rather than
  segmenting reject the field and need `vadEvents: false`.
- Swap the transcription model ids before OpenAI's 2027-02-26 shutdown:
  `gpt-4o-transcribe` and `gpt-4o-mini-transcribe` become `gpt-transcribe` for
  `transcribe` and `gpt-live-transcribe` for `streamTranscriptionFrom`.
  `whisper-1` is still the only model returning `wordTimestamps`, and has no
  replacement yet.
