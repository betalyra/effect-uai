## Removed: `Approval.fromQueue`

`Approval.fromQueue` and its types (`Verdict`, `FromQueueOptions`) are no
longer exported from `@effect-uai/core/Approval`. A verdict queue with a
router fiber and a timeout is one way to wait for approvals, not the only
one, so it now lives as app code in the
[tool call approval recipe](/recipes/tool-call-approval/).

If you use it, copy `fromQueue` and `Verdict` from the recipe's `recipe.ts`
into your app and change the import:

```ts
// before
import * as Approval from "@effect-uai/core/Approval"
const before = Effect.gen(function* () {
  const plan = yield* Approval.fromQueue(isSensitive, verdicts)(calls)
})

// after
import { fromQueue } from "./approval.js" // your copy
const after = Effect.gen(function* () {
  const plan = yield* fromQueue(isSensitive, verdicts)(calls)
})
```

The behavior is the same, including the `timeout` option.

Everything else in `Approval` stays: `fromMap`, `approve`, `reject`,
`splitApprovalDecisions`, `approvalRequested` and `ApprovalDecision`.
