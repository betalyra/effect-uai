# effect-uai

This npm name is **reserved** for the `effect-uai` project. The functional
packages live under the `@effect-uai/*` scope:

- [`@effect-uai/core`](https://www.npmjs.com/package/@effect-uai/core):
  the capabilities and primitives (loop, tools, streaming, speech, realtime,
  images, embeddings, retrieval, messenger, sandboxes).
- [`@effect-uai/openai`](https://www.npmjs.com/package/@effect-uai/openai):
  OpenAI language models, embeddings, speech, realtime and images.
- [`@effect-uai/responses`](https://www.npmjs.com/package/@effect-uai/responses):
  the OpenAI Responses API adapter, also for compatible gateways.
- [`@effect-uai/chat-completions`](https://www.npmjs.com/package/@effect-uai/chat-completions):
  the OpenAI-compatible Chat Completions adapter for gateways.
- [`@effect-uai/anthropic`](https://www.npmjs.com/package/@effect-uai/anthropic):
  Anthropic Claude.
- [`@effect-uai/google`](https://www.npmjs.com/package/@effect-uai/google):
  Google Gemini language models, embeddings, speech, Gemini Live, images and
  Lyria music.
- [`@effect-uai/mistral`](https://www.npmjs.com/package/@effect-uai/mistral):
  Mistral language models and Voxtral speech.
- [`@effect-uai/fal`](https://www.npmjs.com/package/@effect-uai/fal):
  Fal image generation.
- [`@effect-uai/elevenlabs`](https://www.npmjs.com/package/@effect-uai/elevenlabs):
  ElevenLabs speech and music.
- [`@effect-uai/inworld`](https://www.npmjs.com/package/@effect-uai/inworld):
  Inworld speech.
- [`@effect-uai/jina`](https://www.npmjs.com/package/@effect-uai/jina):
  Jina embeddings, reranking and web reading.
- [`@effect-uai/retrieval`](https://www.npmjs.com/package/@effect-uai/retrieval):
  chunking, rank fusion and tokenizers.
- [`@effect-uai/perplexity`](https://www.npmjs.com/package/@effect-uai/perplexity),
  [`@effect-uai/exa`](https://www.npmjs.com/package/@effect-uai/exa),
  [`@effect-uai/tavily`](https://www.npmjs.com/package/@effect-uai/tavily),
  [`@effect-uai/firecrawl`](https://www.npmjs.com/package/@effect-uai/firecrawl):
  web search and web reading.
- [`@effect-uai/browser`](https://www.npmjs.com/package/@effect-uai/browser):
  a real browser as a tool.
- [`@effect-uai/microsandbox`](https://www.npmjs.com/package/@effect-uai/microsandbox),
  [`@effect-uai/deno`](https://www.npmjs.com/package/@effect-uai/deno):
  local and hosted microVM sandboxes.
- [`@effect-uai/mcp`](https://www.npmjs.com/package/@effect-uai/mcp):
  MCP servers' tools as a toolkit.
- [`@effect-uai/telegram`](https://www.npmjs.com/package/@effect-uai/telegram),
  [`@effect-uai/discord`](https://www.npmjs.com/package/@effect-uai/discord),
  [`@effect-uai/slack`](https://www.npmjs.com/package/@effect-uai/slack):
  the agent as a messenger bot.
- [`@effect-uai/ai-sdk`](https://www.npmjs.com/package/@effect-uai/ai-sdk):
  Vercel AI SDK compatibility.

Project repository: https://github.com/betalyra/effect-uai
