## Notes per vendor

**OpenAI.** `gpt-image-2` sits alone at the top of both Arena boards by a wide margin. Images API and Responses API both support mask inpainting, multi-image input (docs show 4 inputs; no hard cap stated), `quality` low/medium/high/auto, and `partial_images` streaming. Shutdowns: `dall-e-2`/`dall-e-3` removed 2026-05-12; `gpt-image-1`, `-1-mini`, `-1.5` shut down 2026-12-01. Sources: [model page](https://developers.openai.com/api/docs/models/gpt-image-2), [guide](https://developers.openai.com/api/docs/guides/image-generation), [pricing](https://developers.openai.com/api/docs/pricing), [deprecations](https://developers.openai.com/api/docs/deprecations), [launch](https://openai.com/index/introducing-chatgpt-images-2-0/).

**Google.** Imagen is dead: docs say "Imagen models are deprecated and will shut down on August 17, 2026" ([source](https://ai.google.dev/gemini-api/docs/imagen)). Everything is Nano Banana now, on the Gemini API via the Interactions API endpoint (`/v1beta/interactions`), not Vertex-only. `gemini-2.5-flash-image` is legacy. Sources: [image gen docs](https://ai.google.dev/gemini-api/docs/image-generation), [pricing](https://ai.google.dev/gemini-api/docs/pricing), [NB2 launch](https://techcrunch.com/2026/02/26/google-launches-nano-banana-2-model-with-faster-image-generation/).

**Microsoft AI** is the surprise: MAI-Image-2.6 shipped today and is #2 T2I / #1 AA editing. Only available via Microsoft Foundry (preview) and OpenRouter passthrough; no standalone REST product outside Azure. Sources: [announcement](https://microsoft.ai/news/pushing-the-quality-cost-frontier-with-mai-image-2-6/), [OpenRouter](https://openrouter.ai/microsoft/mai-image-2.6), [Foundry docs](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-mai-image).

**xAI.** OpenAI-compatible endpoints, cheap, #3 on both boards. Sources: [docs](https://docs.x.ai/docs/guides/image-generation), [pricing](https://docs.x.ai/developers/pricing), [launch](https://x.ai/news/grok-imagine-image-2). Third-party claims of $0.08 for 2K are UNVERIFIED against the docs table.

**Reve.** Top-4 quality but the help center states the API "sunset on August 14th" with credit refunds ([help article](https://help.reve.com/hc/en-us/articles/46837930295316-Reve-API), fetch returned 403; quoted via search snippet). Third-party hosts (Atlas Cloud etc.) still list Reve 2.1; licensing status UNVERIFIED. Not integrable first-party.

**Meta Muse Image.** Cheapest top-5 model at $0.01, OpenAI-compatible endpoint shape. Sources: [Meta dev blog](https://developer.meta.com/ai/resources/blog/build-with-muse-Image/), [fal](https://fal.ai/models/meta/muse-image/text-to-image).

**ByteDance.** Seedream 5.0 Pro is strong on editing (#6). Official IDs `doubao-seedream-5-0-pro-260628` (Volcengine) / `dola-seedream-5-0-pro-260628` (BytePlus) are from third-party guides; BytePlus docs did not render (UNVERIFIED). Sources: [fal](https://fal.ai/models/bytedance/seedream/v5/pro/text-to-image), [Replicate](https://replicate.com/collections/text-to-image), [pricing writeup](https://www.atlascloud.ai/blog/ai-updates/seedream-5-0-pro-price).

**Alibaba.** Qwen-Image-3.0 broke the open-weights pattern (closed) but is on Model Studio with sync and async calls ([docs](https://www.alibabacloud.com/help/en/model-studio/text-to-image), [Unite.AI](https://www.unite.ai/alibaba-launches-qwen-image-3-0-without-benchmarks-or-weights/)). Wan2.7-image-pro is the 4K option.

**BFL.** FLUX.2 remains the image line; FLUX 3 docs say video only, with "Omni Reference with images" coming ([FLUX 3 overview](https://docs.bfl.ml/flux_3/flux3_overview), [FLUX.2 page](https://bfl.ai/models/flux-2), [release notes](https://docs.bfl.ml/release-notes)). Quality-wise it has fallen out of the top 15 on both leaderboards.

**Others.** Ideogram 4.0 went open-weights and is on fal ([GitHub](https://github.com/ideogram-oss/ideogram4)). Recraft is the SVG specialist ([pricing](https://www.recraft.ai/docs/api-reference/pricing.md), [V4.1](https://www.recraft.ai/docs/recraft-models/recraft-v4-1.md)). Kling official API: [kling.ai docs](https://kling.ai/document-api/api/image/3-0-omni/image-generation) (page did not render; fal price used). Luma Uni-1: [page](https://lumalabs.ai/uni-1), [VentureBeat](https://venturebeat.com/technology/luma-ai-launches-uni-1-a-model-that-outscores-google-and-openai-while). MiniMax has no new image model ([models page](https://platform.minimax.io/docs/release-notes/models)). Midjourney no-API claim is from third parties only, but consistent across all ([source](https://unifically.com/blogs/midjourney-api)); UNVERIFIED from Midjourney itself.

## Integration takeaways

1. Quality tier 1 with first-party HTTP APIs: **OpenAI gpt-image-2**, **xAI grok-imagine-image-2.0**, **Meta Muse Image**, **Google Nano Banana 2/Pro**, **ByteDance Seedream 5.0 Pro**. Microsoft MAI-Image-2.6 is #2 but Azure-only.
2. OpenAI, xAI, and Meta share the `/v1/images/generations` + `/v1/images/edits` shape, so one codec could cover three vendors.
3. Reve is out (API sunset); Midjourney never in; Imagen shut down; DALL-E removed.
4. Streaming partials exist only at OpenAI (`partial_images`) and via OpenRouter SSE; BFL and Kling are async-poll.
