## Notes

- Cheapest per image: MiniMax image-01 ($0.0035), Luma Photon Flash ($0.002), FLUX.1 schnell on Together ($0.0027/MP) or fal ($0.003/MP), FLUX.2 klein 4B on fal ($0.005/MP). Klein is the current "fast tier" flagship: BFL and fal both claim sub-second.
- Google's fast tier consolidated: Imagen 4 Fast is gone, Gemini 2.5 Flash Image is deprecated, Nano Banana 2 Lite ($0.0336, 1K only, sub-2s target) is the intended replacement.
- OpenAI's fast/cheap tier is quality `low` on gpt-image-2 ($0.006) or gpt-image-1-mini ($0.005). OpenAI gives no latency numbers; third-party measurements put both in the tens of seconds, so not truly "fast tier" despite the price.
- Fireworks: changelog says image generation deprecated; do not integrate.
- AA leaderboard Elo for context: Nano Banana 2 Lite 1290, Seedream 4.0 1226, Ideogram 4.0 Fast 1182, FLUX.2 klein 9B 1140, GPT Image 1 Mini (medium) 1107, Imagen 4 Fast 1099, SD3.5 Turbo 1035, Photon Flash 1004, FLUX.1 schnell 1000.

## API shapes

1. Sync REST, image inline (base64 and/or URL): OpenAI Images API (b64), Gemini `generateContent` (inline base64), Together, Recraft, Ideogram, xAI, MiniMax, BytePlus ModelArk, Stability (UNVERIFIED). Most use an OpenAI-style `{data:[{url|b64_json}]}` envelope (Together, Recraft, ModelArk, xAI).
2. Async job + polling URL: BFL direct API (POST returns `id` + `polling_url`; poll every ~0.5s; result is a signed URL valid 10 minutes; no webhooks; 24 concurrent task cap). Luma (generation id, poll or `callback_url` with 3 retries).
3. Both: fal (`fal.run` sync with client timeout, `queue.fal.run` submit/status/result with SSE status streaming and `webhook_url`).
4. Partial-image streaming: only OpenAI (Images API and Responses API `partial_images` 0-3, event `response.image_generation_call.partial_image`). No equivalent found for Gemini, fal, Together, BFL.

Suggested abstraction: a single `generate` returning `Effect<Image>` where Image is `{ bytes | url }`, with provider adapters hiding the async-poll loop (BFL, Luma) and optional `Stream<PartialImage>` only for OpenAI.
